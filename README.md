# Бот: свободные даты экзамена по вождению (Женева)

Каждые ~10 минут GitHub сам заходит на ge.ch под вашим номером, смотрит свободные даты
практического экзамена (кат. B, OCV Carouge) до 31.03.2027 и, если что-то появилось,
пишет вам в Telegram. Компьютер и браузер не нужны. **Бот ничего не бронирует** — только сообщает,
записываетесь вы сами по ссылке.

---

## Шаг 1. Создать Telegram-бота (2 минуты)

1. В Telegram откройте **@BotFather** → отправьте `/newbot`.
2. Придумайте имя и логин бота (логин должен заканчиваться на `bot`, например `ge_exam_check_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...` — сохраните его.
4. Найдите своего нового бота в поиске Telegram и нажмите **Start** (или напишите ему что угодно).
5. Откройте в браузере (подставьте свой токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   Найдите там `"chat":{"id":123456789` — это ваш **chat id**.

## Шаг 2. Создать репозиторий на GitHub

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. **New repository** → имя, например `exam-check` → выберите **Public** → Create.
   - Public — потому что для публичных репозиториев GitHub Actions бесплатны без лимита.
     Ваши личные данные туда **не попадают**: они хранятся в Secrets (шаг 3), их никто не видит.
   - Если хотите Private — бесплатно 2000 минут в месяц; тогда поставьте проверку раз в 30 минут
     (строка `cron` в `.github/workflows/check.yml`: `"*/30 * * * *"`).
3. Загрузите файлы: **Add file → Upload files** и перетащите:
   - `check_slots.py`
   - папку `.github` (внутри `workflows/check.yml`).
     Если папка с точкой не перетаскивается: **Add file → Create new file**, в имени напишите
     `.github/workflows/check.yml` и вставьте содержимое файла.
4. **Commit changes**.

## Шаг 3. Добавить секреты

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Создайте 5 штук:

| Имя | Что вписать |
|---|---|
| `DISPO_NO_REGISTRE` | номер регистра, которым вы входите на сайт (N° de registre) |
| `DISPO_BIRTHDAY` | дата рождения, `ДД.ММ.ГГГГ` |
| `DISPO_RDV_ID` | номер из ссылки: `20261115161803480` |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | chat id из шага 1 |

## Шаг 4. Запустить и проверить

1. Вкладка **Actions** → если просит, нажмите «I understand… enable workflows».
2. Слева **Проверка дат экзамена** → **Run workflow**.
3. Через минуту откройте запуск → шаг «Проверить свободные даты». Должна быть строка
   `Проверено до 31.03.2027: свободных слотов N`.
4. Дальше он будет запускаться сам каждые ~10 минут.

## Что приходит в Telegram

- 🚗 **Найдены свободные даты** — список дат и времени + ссылка. Повторно то же самое не присылает,
  только если список изменился.
- ⚠️ **Проверка не сработала** — например, не удалось войти, сайт изменился или ссылка устарела.
  Про одну и ту же ошибку сообщает один раз.

## Как остановить

**Actions → Проверка дат экзамена → «…» → Disable workflow.**

## Если что-то не работает

- «Не удалось войти» — проверьте номер и дату рождения в секретах. Если на сайте при входе
  появилась капча («я не робот») — бот войти не сможет, это нормально, тогда остаётся проверка
  с компьютера.
- HTTP 403 / ошибки соединения — сайт может блокировать серверы GitHub. Тогда бот так работать не сможет.
- Если вы перенесли экзамен на другую дату, номер в ссылке может поменяться — обновите `DISPO_RDV_ID`.
